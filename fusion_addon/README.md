# Fusion 360 用 ロケットデータエクスポートスクリプト (`Rocket_Export`)

このスクリプトは、Fusion 360 の現在のモデルから**「高精度外形STL」**と**「各パーツの物理・幾何情報JSON」**をワンクリックで同時にエクスポートします。

---

## 1. 導入手順（Fusion 360）

1. Fusion 360 を起動します。
2. 画面上部メニューの **[ユーティリティ]** タブ → **[アドイン]** → **[スクリプトとアドイン]**（ショートカット: `Shift + S`）を開きます。
3. **[スクリプト]** タブの「マイ スクリプト」の横にある **[＋] (作成または追加)** ボタンをクリックします。
4. 本フォルダ内の `Rocket_Export` フォルダ（`D:\1_Stuff\0_programming\0_Project\ロケットシミュレーター\fusion_addon\Rocket_Export`）を選択します。
5. リストに追加された **`Rocket_Export`** を選択し、**[実行]** をクリックします。

---

## 2. 推奨されるCADモデリング・命名ルール

スクリプトは、ボディやコンポーネントの**名前**から自動的にパーツ種別やパラメータを判定します。

| パーツ種別 | 推奨オブジェクト名（例） | 自動認識される内容 |
| :--- | :--- | :--- |
| **エンジン / モーター** | `Motor_C6-5`<br>`Engine_A8-3`<br>`Motor_D12` | 型番（`C6-5` 等）を自動検出し、シミュレータ側で推力曲線・燃焼質量変化を紐付け。配置位置・ノズル向きも座標から自動特定。 |
| **パラシュート** | `Parachute_30cm`<br>`Chute_45cm` | 直径（30cm 等）を自動抽出。`horizontal_descent: true`（横向き降下ギミック）を自動付与。 |
| **ストリーマ** | `Streamer`<br>`Ribbon_5x100` | ストリーマ回収として自動認識。 |
| **バラスト / 重り** | `Ballast_10g`<br>`Weight_5g` | ノーズコーン内の重りとして認識。指定グラム数（10g 等）を自動適用。 |
| **機体構造（一般）** | `Fuselage`<br>`Fin_1`, `Fin_2`<br>`NoseCone` | 機体外殻構造として認識。CAD上の材料（PLAなど）と体積から質量・重心・慣性テンソルを計算。 |

> [!TIP]
> - **非表示ボディ**: 一時的に非表示（目のアイコンOFF）にしているボディは、`is_visible: false` となりシミュレーションから自動除外できます。
> - **重量の実測上書き**: エクスポートされた JSON の `mass_g_override` に実測値を書き込むことで、後から微調整できます。

---

## 3. 出力ファイル

実行すると、指定したフォルダ（デフォルト: `.../ロケットシミュレーター/export`）に以下が保存されます：
1. **`[デザイン名].stl`**: 空力解析・メッシュ計算用の外表面データ
2. **`[デザイン名]_params.json`**: 各パーツの重心、質量、慣性テンソル、寸法、マテリアル情報
